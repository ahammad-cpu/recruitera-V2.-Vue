# Career Site UI Spec

One file per page. Each file is complete on its own (rules, theme, header,
footer and all page details), so hand over one file at a time.

| File | Page |
|---|---|
| `01-careers-home.md` | Home: hero, featured jobs, values, culture video, testimonials |
| `02-careers-opportunities.md` | Opportunities: job list with filters, search and pagination |
| `03-careers-job-detail.md` | Job detail: Overview tab, Application form, closed / submitted / not-found states |

Every file tells the implementing project to keep its own stack and build the
page with its existing design system and components.
